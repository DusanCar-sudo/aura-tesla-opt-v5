# Aura TESLA Opt. V5 website
Static HTML/CSS/JavaScript with self-hosted fonts and supplied imagery.

Run from the project root:

```sh
python3 -m http.server 4187 --directory WEB
```

Open http://localhost:4187. Serve over HTTP for the interactive BOM JSON to load. Deploy the contents of WEB to any static host. No build or dependencies required.

The parts table uses the local export `aura_tesla_opt_files (5)`. Its estimates are historical design data, not a selling price. The live Blueprint has a different parts revision. Concept art is labeled and the incomplete installation guide is not offered as a finished manual.
